## What Every Workflow Should Include

1. Problem being solved.
2. Intended user and use case.
3. Required tools and accounts.
4. Workflow architecture.
5. Step-by-step setup instructions.
6. Inputs, outputs, and integrations.
7. Error handling and recovery.
8. Security and privacy considerations.
9. Cost considerations, where verified.
10. Testing instructions and known limitations.

## Reliability Standards

- Validate inputs before processing.
- Handle API failures and unexpected responses.
- Avoid duplicate actions where possible.
- Protect credentials and sensitive information.
- Include human approval for high-impact actions.
- Document what has been tested and what remains unverified.
