# 🛠️ Claude Skills Library

Welcome to the Kinetix AI Vault Skills Library.

This collection is dedicated to practical, reusable skills designed to extend Claude's capabilities across research, business, coding, productivity, marketing, and AI development.

## Skill Collections

| Category | Purpose |
|---|---|
| Research Skills | Research, investigation, and analysis |
| Business Skills | Strategy, planning, and decision-making |
| Coding Skills | Software development and debugging |
| Marketing Skills | Content, copywriting, and growth |
| Productivity Skills | Organization and task management |
| AI Agent Skills | Agent workflows and tool usage |
| Claude Code Skills | Developer workflows and coding assistance |

## What Every Skill Should Include

Each skill should have:

- A clearly defined purpose.
- Accurate skill metadata.
- Instructions for when and how to use it.
- A practical workflow.
- Relevant examples.
- Supporting reference files when necessary.
- Documented limitations and compatibility.

## Skill Structure

Each individual skill will live in its own folder:

```text
skills/
├── README.md
├── claude/
│   └── skill-name/
│       └── SKILL.md
└── claude-code/
    └── skill-name/
        └── SKILL.md
```

## Quality Standards

- Follow the official supported Skills format.
- Keep instructions clear and practical.
- Avoid duplicate or unnecessary instructions.
- Test skills where possible.
- Document compatibility and known limitations.
- Never claim a skill has been tested unless it has actually been tested.
