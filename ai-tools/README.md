## How We Evaluate Tools

Every tool guide should cover:

1. Official website and product description.
2. Main purpose and target audience.
3. Practical use cases.
4. Key features and strengths.
5. Limitations and drawbacks.
6. Pricing, when verified.
7. Alternatives and comparisons.
8. Last verification date.

## Research Standards

- Prefer official product documentation.
- Verify current pricing before publishing.
- Distinguish personal testing from independent research.
- Never invent features or performance claims.
- Clearly identify outdated or unverified information.
